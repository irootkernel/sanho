# Architecture Decision Records

This index owns durable records of accepted, superseded, deprecated, and
rejected architecture decisions and their rationale.

No standalone architecture decision records are currently registered. Add a
record here when preserving the rationale separately from the current-state
architecture materially improves future decisions. Register every record in
this index and state its status and relationship to the canonical
[`architecture.md`](../architecture.md).

Do not reconstruct historical decisions speculatively from release notes or
Git history.
