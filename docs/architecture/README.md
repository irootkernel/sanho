# Architecture

[`../architecture.md`](../architecture.md) is the canonical architecture and
implementation authority for Sanho. It owns current components, package
boundaries, runtime and Git flows, provenance, persistence, concurrency, and
safety contracts.

This index provides role ownership without moving the established authority.
Architecture history belongs in Git and the changelog; accepted structural
rationale that must remain independently discoverable belongs in
[`../architecture-decision-records/`](../architecture-decision-records/README.md).
