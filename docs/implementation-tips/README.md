# Implementation Tips

This index owns non-normative guidance for developing, validating, and
releasing Sanho.

- [`../hands-on-testing.md`](../hands-on-testing.md) defines the real-environment
  release verification checklist.
- The root [`Makefile`](../../Makefile) is the executable entrypoint for
  repository-standard generation, lint, build, and test workflows.
- [`../../AGENTS.md`](../../AGENTS.md) defines repository operating guidance
  for coding agents.

Required product behavior belongs in specifications, current structure belongs
in architecture, and live-environment procedures belong in operations.
